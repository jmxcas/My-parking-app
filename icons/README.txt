PARKED APP ICONS
================

Place the following icon files in this folder:

  icon-192.png  —  192×192 pixels
  icon-512.png  —  512×512 pixels

These icons are used for:
  • The PWA home screen icon (when installed on a phone)
  • The app splash screen
  • The browser tab favicon (if you also add a favicon.ico/favicon.png to the root)

Recommended design:
  • Dark background (#0a0a0f) with the accent colour (#e8ff47)
  • Simple "P" lettermark or parking symbol
  • Use a maskable icon safe zone (centre 80% of the canvas) for Android adaptive icons

You can generate icons for free at:
  https://maskable.app/editor
  https://realfavicongenerator.net

Once both files are in this folder the PWA install prompt will work correctly.
